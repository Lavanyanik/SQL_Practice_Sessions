# 🗄️ SQL 60 Days Challenge

This repository documents my 60-day journey from SQL fundamentals to advanced SQL and interview-level problem solving.

> Learn SQL. Practice daily. Think in queries. 🚀

---

## 🎯 Goal

The goal of this challenge is to build strong SQL fundamentals, develop practical query-solving skills, and progress toward advanced SQL and interview-level problems.

---

## 🗺️ Learning Roadmap

| Phase | Days | Focus |
|------|------|------|
| 🟢 Fundamentals | 01–05 | SQL basics |
| 🔵 Filtering & Sorting | 06–10 | `WHERE`, operators, `ORDER BY` |
| 🟣 Aggregations | 11–15 | `GROUP BY`, `HAVING`, aggregate functions |
| 🟠 Joins | 16–21 | `INNER`, `LEFT`, `RIGHT`, `FULL`, `SELF`, `CROSS JOIN` |
| 🟡 Subqueries | 22–26 | Subqueries, `EXISTS`, correlated subqueries |
| 🔷 CTEs | 27–30 | CTEs and recursive CTEs |
| 🟤 String & Date Functions | 31–35 | Text and date manipulation |
| 🔴 Window Functions | 36–43 | Ranking, `LAG`, `LEAD`, running totals |
| ⚫ Advanced SQL | 44–53 | Advanced queries, optimization, indexes, transactions |
| 🏆 Interview Challenge | 54–58 | Interview-level SQL patterns |
| 🔄 Revision | 59–60 | Review and assessment |

## 📚 Topics Covered

### 🟢 SQL Fundamentals

- `SELECT`
- `DISTINCT`
- Aliases
- `NULL`
- Basic expressions

### 🔍 Filtering & Sorting

- `WHERE`
- Comparison operators
- `AND` / `OR` / `NOT`
- `IN` / `NOT IN`
- `BETWEEN`
- `LIKE`
- `IS NULL` / `IS NOT NULL`
- `ORDER BY`
- `LIMIT` / `OFFSET`

### 📊 Aggregations

- `COUNT`
- `SUM`
- `AVG`
- `MIN` / `MAX`
- `GROUP BY`
- `HAVING`
- Conditional aggregation

### 🔗 Joins

- `INNER JOIN`
- `LEFT JOIN`
- `RIGHT JOIN`
- `FULL OUTER JOIN`
- `SELF JOIN`
- `CROSS JOIN`
- Multiple-table joins

### 🧩 Subqueries & CTEs

- Scalar subqueries
- Multi-row subqueries
- `EXISTS` / `NOT EXISTS`
- Correlated subqueries
- CTEs
- Multiple CTEs
- Recursive CTEs

### 🔤 String & Date Functions

- String manipulation
- Text cleaning
- Date extraction
- Date arithmetic
- Date formatting

### 📈 Window Functions

- `OVER()`
- `PARTITION BY`
- `ROW_NUMBER()`
- `RANK()`
- `DENSE_RANK()`
- `NTILE()`
- `LAG()`
- `LEAD()`
- Running totals
- Moving averages
- Top-N per group

### 🚀 Advanced SQL

- Set operations
- Advanced aggregations
- Recursive queries
- Views
- Temporary tables
- Transactions
- Indexes
- `EXPLAIN`
- Query optimization

### 💼 Interview SQL

- Ranking problems
- Top-N problems
- Duplicate detection
- Gaps and islands
- Consecutive records
- Complex joins
- Multi-step analytical queries
